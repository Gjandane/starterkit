# House style files

One saved House style is one Markdown file, named for the style in kebab-case. It holds what any page on any subject can follow:

````markdown
# House style: <name>

## Principles

- **Ink:** <how lines, frames and details are drawn>
- **Lettering:** <which words take the title face, and how titles, headings and labels relate>
- **Drawings:** <how large they are against the words, and what kind of thing they show>
- **Shadows:** <what casts one, and what stays flat>
- **Arrows:** <their weight against the outlines, and how they lead the eye>
- **Colour cues:** <each cue by name: where on a drawing it goes, and how much of it>

## Style rules

```json
<a complete style.json>
```
````

- The style rules are valid `inking` style rules. A principle says only what they cannot.
- A cue is named for its colour. Its meaning and its symbol belong to each study set.
- A page structure (a reading path, a panel arrangement, a feature every panel repeats) appears only as an option, worded as what a page may do. Each page chooses its own.
- Paper, margins, density, orientation, icons, words from a source, file paths and any drawing, word or mark from a reference image stay out. A Look taken from one saves like any other.

`principles.md` in a run holds the six Principles bullets alone.

## Save

Only after the learner approves a sample and says yes to a name. When that name is taken, ask for another: changing a saved style is an update.

Write the file from the approved `principles.md` and `style.json`. Done when the file exists, its JSON block holds the same values as the approved `style.json` and the learner has its name and path.

## Update

Only when the learner asks for the saved style itself to change. Apply exactly the changes they name. "Save this run's corrections" names every principle and style rule where the run's copy differs from the file.

A study set keeps the rules it was approved with: the files under `sketchnotes/` change only when the learner asks for that too. Done when the learner has seen each changed line, before and after, and every other line of the file is as it was.
